# CreativeLock Feedback

This repository is the public place to report problems and suggest improvements for the CreativeLock Paper plugin.

## Share feedback

- [Report a bug](https://github.com/mickhod/CreativeLock-Feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/mickhod/CreativeLock-Feedback/issues/new?template=feature_request.yml)

Please search existing issues before opening a new one. Add clear steps to reproduce bugs and describe what you expected to happen.

## Helpful details

For bug reports, include the CreativeLock version, server software and Minecraft version, Java version, and FAWE or WorldEdit version when relevant. Also mention the player's game mode and relevant CreativeLock permissions.

The only server build verified so far is Paper 26.1.2 (build 74) on Java 25. Compatibility with other Paper versions and with Spigot/Bukkit has not been verified. FastAsyncWorldEdit is optional; it is needed for FAWE edit tracking and WorldEdit selection features.

## Keep private information out of issues

Issues are public. Remove passwords, database credentials, access tokens, private player information, and other sensitive details from logs, screenshots, and configuration before posting.
